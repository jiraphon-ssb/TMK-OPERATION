## ของที่ "คง" ไว้ (ไม่แตะกลไก — ลดความเสี่ยง)
- โครง shadcn Sidebar เดิมทั้งชุด (ย่อเป็นไอคอนได้ · มือถือเป็น drawer เหมือนเดิม)
- `go()` + สิทธิ์ล็อกหน้า (`locked_sections`) — หน้าโดนล็อก = จาง + กุญแจ เหมือนเดิมทุกจุด
- badge ตัวเลข (งานของฉัน) · จุดแดงเวอร์ชันใหม่ · Spotlight ⌘K · ผู้ใช้/ออกจากระบบ
- `NAV_DEF` เป็นแหล่งข้อมูลเดิม — เพิ่มแค่ metadata (อันไหนเป็น tile / จัดกลุ่มไหน)

## ของที่ "เปลี่ยน"
| เดิม | ใหม่ |
|---|---|
| เมนูหลัก 5 อัน กดกางเห็น sub (accordion) | **ไม่มี accordion** — tile 4 + แถวแบนจัดกลุ่ม เห็นทุกหน้าทันที |
| "มีอะไรใหม่" ปักถาวรใน footer | การ์ดไฮไลต์บนสุด **เฉพาะตอนมีของใหม่** · อ่านแล้วหาย (ยังเข้าได้จากเมนูผู้ใช้) |
| โครงการมี sub 7 อัน (บอร์ด/ปฏิทิน/คานบัง/ไทม์ไลน์/ลิสต์/ของฉัน/ประวัติ) | เหลือ **3 แถว** (งาน/บอร์ด · งานของฉัน · ประวัติ) — ปฏิทิน/คานบัง/ไทม์ไลน์/ลิสต์ สลับในหน้าบอร์ดเองซึ่งมีแท็บอยู่แล้ว |
| ยอดขาย/Sale ต้องกางก่อนเห็นหน้า | เห็นแบนหมดใต้หัวข้อ "ยอดขาย" / "ทีมเซลล์" |

- โหมดย่อ (icon): tile ยุบเป็นแถวไอคอนเดี่ยวอัตโนมัติ — ฟีเจอร์ย่อไม่หาย
- ลิสต์โครงการรายตัว (FlowsNav ปักโครงการ) ย้ายไปอยู่ใต้แถว "งาน/บอร์ด" เหมือนเดิม
