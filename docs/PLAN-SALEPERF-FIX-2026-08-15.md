## 🐛 จุดที่ 1 (ภาพ1+ภาพ5) — % ที่ผิดปกติ: เจอต้นตอแล้ว 2 บั๊กคนละแบบ

### บั๊ก A · %ปิดต่อช่องทาง โผล่ 1000% (ภาพ1 · Phone)
- **ต้นตอ:** `closeRate = ออเดอร์ ÷ คนทัก × 100` **ไม่มีเพดาน** (`salePerfAgg.js:84`)
- Phone: คนทัก 2 · ออเดอร์ 20 → 20/2 = **1000%**
- **ความจริง:** ออเดอร์ Phone มีจริง แต่ "คนทัก Phone" แทบไม่ได้กรอก → ตัวหาร (คนทัก) น้อยเกิน = % ระเบิด · %ปิด > 100% **แปลว่าคนทักกรอกไม่ครบเสมอ** (ปิดมากกว่าคนที่ทัก เป็นไปไม่ได้)
- **เสนอแก้:** ถ้า ออเดอร์ > คนทัก (จะเกิน 100%) → **ไม่โชว์ % มั่ว** แต่โชว์ตัวเลขดิบ "20 ปิด / 2 ทัก" + ป้ายจาง **"คนทักไม่ครบ"** แทน · ช่องทางที่คนทักครบ (เช่น Facebook 289/31=11%) โชว์ % ปกติเหมือนเดิม

### บั๊ก B · การ์ดเซลล์/ทีมโชว์ ▲755% / ▲8600% / ▲1517% (ภาพ1+ภาพ5)
- **ต้นตอ:** `deltaPct = (เดือนนี้ − เดือนก่อน) ÷ เดือนก่อน × 100` (`salePerfAgg.js:17`)
- ข้อมูลจริงเริ่ม **มิ.ย. 69** → เทียบ ส.ค. กับ ก.ค. ที่ยอดยังน้อยมาก → % โตพุ่งทุกคน (ไม่ผิดสูตร แต่**ไร้ประโยชน์+ดูน่าตกใจ**)
- **เสนอแก้ (ให้อ่านรู้เรื่อง):**
  - เดือนก่อน = 0 หรือน้อยมาก → โชว์ป้าย **"ใหม่"** (แทน ▲∞%)
  - % เกินเพดาน (เช่น > 300%) → cap เป็น **"▲ 300%+"** (ไม่โชว์ 8600%)
  - ปกติ (≤300%) → โชว์เลขจริงเหมือนเดิม
  - *(พอมีประวัติ ≥2 เดือนเต็ม อาการนี้จะหายเอง — การ cap แค่กันช่วงข้อมูลยังน้อย)*

**ความเสี่ยง:** ต่ำ — แก้แค่ "การแสดงผล %" ไม่แตะยอด/คอม/สูตรเงิน · มีเทสครอบ deltaPct + closeRate

## 🎨 จุดที่ 2 (ภาพ2) — รื้อ UI/UX หน้า "เป้าขาย & คอมมิชชั่น" ใหม่ทั้งหมด

**ปัญหาปัจจุบัน:** ตารางแบนๆ กรอกช่องละคน · ปุ่ม "บันทึก" รายแถวเยอะ · วันตัดรอบเบียดมุมขวา · ไม่เห็นภาพรวมว่าใครตั้งครบ/ยังขาด

**เสนอดีไซน์ใหม่ (ให้ใช้ง่ายสุด):**
1. **แยกเป็นการ์ดรายคน** (แทนตารางแถวยาว) — แต่ละการ์ด: avatar+ชื่อ · ช่อง เป้ายอด / คอม% / เป้า CRM ในการ์ด · สถานะ "ตั้งครบ ✓ / ยังขาด" ชัด
2. **บันทึกอัตโนมัติเมื่อพิมพ์เสร็จ (blur)** — ตัดปุ่ม "บันทึก" รายแถวออก · เหลือ toast ยืนยัน · (ยังมี "บันทึกทั้งหมด" สำรอง)
3. **แถบสรุปบนสุด** — เซลล์ทั้งหมด X คน · ตั้งเป้าแล้ว Y · เป้ารวม ฿ · เป้า CRM รวม ฿ (คงของเดิมแต่จัดให้เด่น)
4. **วันตัดรอบค่าคอม** — ยกเป็นแถบของตัวเอง (ไม่เบียด) พร้อมคำอธิบายรอบ
5. **ตัวช่วยกรอกเร็ว** — ปุ่ม "ใช้เรทเดียวกันทุกคน" (ตั้ง % ทีเดียวทั้งทีม)

> ❓ **ขอเลือกสไตล์:** (ก) การ์ดรายคน [แนะนำ] · (ข) คงตารางแต่ขัดให้สวย+auto-save · (ค) พี่มีภาพในหัวแบบไหนบอกได้
