# แผน: หน้ากว้างเต็มจอ + แยก "มีอะไรใหม่" เป็นหน้าของทุกคน + รื้อ UI ใหม่

> **สถานะ: รอยืนยันก่อนลงมือ** · 15 ส.ค. 2569

---

## 1️⃣ แก้ซ้าย-ขวาโล่ง → ทุกหน้ากว้างเต็มจอ

**ต้นตอ (เจอแล้ว):** `index.css:317` — `.content-inner { max-width: 1280px; margin: 0 auto; }`
ทุกหน้าถูกบีบไว้ที่ 1280px กลางจอ → จอกว้างเหลือขอบโล่งซ้ายขวาเยอะ (ตามภาพ 1-2)

**แก้:** ปลด max-width → เนื้อหากางเต็มความกว้าง (เหลือ padding ขอบพองาม)
- แก้จุดเดียว มีผล**ทุกหน้าทั้งแอป**ทันที (รายงาน/ออเดอร์/CRM/โครงการ/ตั้งค่า)
- ตาราง/กริดการ์ดทั้งแอปเป็น responsive grid อยู่แล้ว → กว้างขึ้น = คอลัมน์เพิ่ม/ตารางหายใจขึ้น ไม่พังเลย์เอาต์
- จะไล่เช็คทุกหน้าหลังแก้ ถ้าหน้าไหนกางแล้วโหรงเหรงผิดปกติจะจูนรายหน้า

## 2️⃣ "มีอะไรใหม่" แยกออกจากตั้งค่า — เป็นหน้าของตัวเอง ทุกคนดูได้ตลอด

**ปัญหาเดิม:** เป็นแท็บใต้ "ตั้งค่า" → ใครโดนล็อกหน้าตั้งค่า = อดดู · แถมรอบก่อนผมทำการ์ดแบบ "อ่านแล้วหาย" → หาทางกลับเข้ายาก (พี่ท้วงถูกแล้ว)

**แก้:**
- สร้าง **section ใหม่ `whatsnew`** — ไม่ผูกกับ settings · **ไม่มีล็อกสิทธิ์ = ทุกคนเข้าได้เสมอ**
- **แถวถาวรใน sidebar** กลุ่ม "ระบบ": `✨ มีอะไรใหม่` (+จุดแดงตอนยังไม่อ่าน) — อยู่ตลอด ไม่หาย
- การ์ดไฮไลต์บนเมนู **คงไว้เป็นตัวเตือน** ตอนมีเวอร์ชันใหม่ (กดแล้วไปหน้าเดียวกัน) — อ่านแล้วการ์ดยุบ แต่**แถวถาวรยังอยู่**
- เอาแท็บ "มีอะไรใหม่" ออกจากหน้าตั้งค่า + เมนูโปรไฟล์ชี้ไปหน้าใหม่

## 3️⃣ รื้อ UI หน้า "มีอะไรใหม่" ใหม่หมด — คลีน+สวยสุด

**ดีไซน์ใหม่ (timeline release notes สไตล์แอปใหญ่):**
```
        มีอะไรใหม่
        อัปเดตล่าสุดของระบบ TMK          [v3.22.0 ล่าสุด]

   ●━━ v3.22.0 · 15 ส.ค. 69 ────────── [ใหม่]
   ┃   ┌────────────────────────────────┐
   ┃   │ ⊞  เมนูข้างรื้อใหม่ทั้งชุด …     │  ← แถวละฟีเจอร์: ไอคอนใน chip กลม
   ┃   │ ⚡ ใหม่: "ทางลัด" ส่วนตัว …     │     + ข้อความ อ่านง่าย
   ┃   │ ✨ "มีอะไรใหม่" เปลี่ยนเป็น …   │
   ┃   └────────────────────────────────┘
   ●━━ v3.21.0 · 15 ส.ค. 69
   ┃   │ 🎯 หน้าตั้งเป้า/คอม …          │
   ┃   ⋯ (รุ่นเก่าถัดลงไป · จางลงนิด)
   ●━━ v3.20.0 · 13 ส.ค. 69
```
- **เส้น timeline + จุด** ไล่รุ่นบน→ล่าง · รุ่นล่าสุดมีขอบ accent + ป้าย "ใหม่"
- ป้ายเวอร์ชันเป็น pill สีตามประเภท (feature=ม่วง accent · improvement=เขียว)
- แถวรายการ = ไอคอนใน chip กลมพื้นจาง + ข้อความ (แบบเดิมเป็นลิสต์แบนๆ)
- คอลัมน์อ่านกลางหน้า (~860px) — หน้าอ่านยาวคอลัมน์แคบกว่าอ่านสบายกว่า (หน้า data เท่านั้นที่กางเต็ม)
- เข้าหน้าแล้ว mark ว่าอ่านแล้ว (จุดแดงดับ) — กลไกเดิม `useUnseenVersion` คงไว้
